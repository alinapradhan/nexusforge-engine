# Service Boundaries

| Service | Responsibility | Key APIs |
|---|---|---|
| Identity | Registration, login, sessions, tokens | `/v1/auth/*` |
| User | User profile and preferences | `/v1/users/*` |
| Product | Product lifecycle and metadata | `/v1/products/*` |
| Catalog | Categories and catalog organization | `/v1/catalog/*` |
| Search | Product/content search | `/v1/search/*` |
| Recommendation | Personalized recommendations | `/v1/recommendations/*` |
| Feed | Feed sessions and ranked items | `/v1/feed/*` |
| Subscription | Plans, lifecycle, entitlements | `/v1/subscriptions/*` |
| Payment | Payment lifecycle and refunds | `/v1/payments/*` |
| Order | Order lifecycle | `/v1/orders/*` |
| Notification | User notifications | `/v1/notifications/*` |
| Analytics | Product and business events | `/v1/analytics/*` |
