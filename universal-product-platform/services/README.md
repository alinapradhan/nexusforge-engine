# Services

Each directory represents a service boundary. Implementations can be added independently.

Recommended ownership:

- identity: authentication and identity
- user: profiles and preferences
- product: product lifecycle
- catalog: categories/catalog
- search: search behavior
- recommendation: candidate generation and ranking
- feed: feed sessions and delivery
- subscription: plans and lifecycle
- payment: payment lifecycle
- order: orders
- notification: notifications
- analytics: event collection
